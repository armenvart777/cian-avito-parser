# Парсер ЦИАН + Авито

Парсит объявления о продаже недвижимости с ЦИАН и Авито, фильтрует по районам и типу продавца (только частные лица). Новые объявления отправляются в MAX мессенджер и сохраняются в Excel.

## Что умеет

- Парсинг ЦИАН через встроенный JSON в HTML (несколько fallback-паттернов)
- Парсинг Авито с ротацией прокси и cookie warmup
- Фильтрация по районам, возрасту объявления, типу продавца
- Уведомления в MAX с inline-кнопками и меню
- Экспорт в Excel (openpyxl), поддержка нескольких форматов файла
- Локальный HTTP прокси-мост для Froxy (обход ограничения curl_cffi на спецсимволы в пароле)
- Защита от повторных уведомлений через seen_ids

## Стек

- Python 3.11+
- curl_cffi - HTTP с имперсонацией браузера
- aiohttp - async запросы для MAX API
- openpyxl - работа с Excel
- beautifulsoup4 - HTML fallback парсинг

## Запуск

```bash
cp .env.example .env
# заполнить .env
pip install -r requirements.txt
python main.py
```

Бот MAX запускается отдельно:

```bash
python max_bot.py
```
